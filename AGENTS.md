# transceiver-exporter — contributor and agent instructions

Prometheus exporter that reads pluggable-optic EEPROM through `ethtool` and exposes transceiver
telemetry. Go, two packages, ~860 lines. Originally `wobcom/transceiver-exporter`; the module path
is now `github.com/rknightion/transceiver-exporter` but it still depends on `github.com/wobcom/go-ethtool`.

Claude Code and Codex both read this file. `CLAUDE.md` is a one-line import of it so the two cannot
drift apart — put instructions here, never there.

## The gate

```bash
go build ./...
go vet ./...
go test -race ./...
golangci-lint run
```

These are the four items every new task inherits as its definition of done. CI additionally
verifies the Docker build; `coverage` is deliberately not a required check.

**The gate cannot see the hardware.** The exporter's real work is decoding EEPROM from physical
optics on a Linux host — there is no such host in CI, no simulator and no captured-EEPROM fixtures.
A green gate on a decoding change proves it compiles and lints, not that it is correct. Say which
claims are gate-backed and which are reasoned; do not collapse the two. The **Wave operating model**
document owns the consequences of this and the recurring defects it produces.

## Commits and releases

Conventional Commits are load-bearing: **release-please derives the version bump from commit
subjects**, and a `!` or `BREAKING CHANGE:` produces a major. Never hand-edit `CHANGELOG.md`,
`.release-please-manifest.json`, or a version literal in Go source — release-please owns all three
and a hand edit either loses to it or corrupts its state.

Several paths are generated by the `rknightion/m7kni-net-site` docs hub at build time and are
gitignored on purpose (`zensical.toml`, `docs/overrides/`, `docs/stylesheets/brand.css`, the project
icons, the social card, `docs/fonts/`). Do not create them locally to "fix" a missing theme.

## Task tracking

The board is the queue: `backlog task list --plain`. `ROADMAP.md` is historical — its completed
items are `Done` tasks `TXE-0001`…`TXE-0007`, and its two unchecked items were stale when this
tracker was adopted on 2026-08-14.

Two campaign documents, both loaded on demand with `backlog doc view` (`backlog doc list --plain`):

- **Agent fan-out protocol (canonical)** — read before designing a wave. Imported verbatim; it is
  the whole campaign model.
- **Wave operating model** — read for this project's own rules: the hardware boundary, the recurring
  defects with their concrete instances, lane conventions, ownership and the escape hatch.

Four rules, each of which prevents a **silent** loss:

**Never use `--notes` or `--plan` bare.** They replace the whole section at exit 0, destroying
another session's writes with no warning. Use `--append-notes` and `--append-plan`. This is an open
upstream bug, not a misunderstanding, and `.claude/hooks/backlog-guard.py` denies the bare forms.

**Never hand-edit task, draft, doc, decision or milestone markdown.** Section boundaries are
HTML-comment markers; break one and the section is silently dropped at exit 0 — still in the file,
invisible to the CLI — until the next write destroys it for real. There is no repair command;
`backlog doctor` only fixes duplicate task IDs. The guard hook denies these edits too.
`backlog/config.yml` is the one exception and may be edited by hand, because list-valued keys
cannot be set through `backlog config set`.

**Finalize in one call**, so an interrupted agent cannot leave finished work looking unfinished:

```bash
backlog task edit TXE-0007 --check-ac 1 --check-ac 2 -s Done
```

**`backlog/` is committed, so no real identifiers in tasks, docs or decisions** — no email
addresses, handles, account IDs, host or device names, addresses or coordinates. Write the shape,
not the instance. Aggregate counts, timings and structural findings are fine. Sweep before
committing:

```bash
grep -rniE "rob-knight\.net|@gmail|@rob-knight|[0-9]{1,3}(\.[0-9]{1,3}){3}" backlog/ && echo "PII FOUND"
```

Never let two agents edit the same task: v1.50.x fixed the concurrent-edit race in the edit funnel
but not in reorder, draft saves, the TUI path, `doc update` or decision updates.
